# 界面说明、深浅色与小屏幕

## 功能说明

带 ⓘ 的标题或说明按钮默认不展开解释。鼠标停留 650 毫秒后显示批注，短暂经过会取消；指针可以移入批注阅读。键盘 Tab 聚焦可阅读，点击/触屏点按可开关。Escape 或点按外部关闭。弹窗内先关闭批注，再按 Escape 才关闭弹窗。

这是显式选择的说明组件，不会把所有 `.hint` 文本一概隐藏。版权授权、API 费用和发送范围、错误、运行状态、必选项、导出兼容限制与操作中的必要指引仍直接显示。文章正文、模块文字与导出内容不属于功能说明。

## 界面主题

工具栏「界面主题」提供浅色、深色、自动三种模式，默认自动。自动使用设备**当前本地时区**的时钟：07:00（含）至 19:00（不含）浅色，其余时间深色。这是固定昼夜时段，不是按经纬度计算日出日落，不请求定位权限。

选择保存在当前浏览器本机；禁用存储时本次页面仍可切换。自动模式按分钟复算，并在回到页面/恢复标签时更新；每次使用当前本地小时，不缓存时区偏移，因此会跟随设备时区和夏令时变化。手动选择优先于时间，直到重新选择自动。

仅编辑器界面换色，文章画布、导入 HTML、模板预览、图片及输出维持自身配色。界面主题不同于文章的视觉主题。

## 小屏幕验收

Playwright 覆盖手机 390×844、平板 820×1180 与横屏视口。检查工具栏可达、标题编辑/保存、导入/设置/预览弹窗、触屏说明、深浅色切换与持久化。模拟视口不等于真实 iOS Safari/iPadOS 真机验收。
