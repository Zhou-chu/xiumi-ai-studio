# 正文选区字体与格式维护规范

## 功能与范围
- 在正文模块双击进入编辑，可选择字体、字号（12–48px 常用档位），并使用加粗、斜体、下划线、主题色、强调色及自选文字颜色。
- 适用于 paragraph、card、imageText 的富文本正文，以及导入的原样 HTML。应用 UI 字体与作品内容字体严格分离。
- 富文本有选区时只改选中文字；光标收起时只影响后续输入。原样 HTML 必须先选择文字，没有选区不更改任何正文。
- 混合粗体选区再次加粗会统一加粗，再次操作取消。HTML 按钮提供混合状态，不误报全部已启用。
- 字体使用当前实际加载的 Noto Sans/Serif SC Variable 名称，并附带系统字体回退。楷体、仿宋、Arial 等依赖本机可用字体。导出不嵌入字体文件，接收平台可能使用回退字体。
- 控件保留键盘焦点，避免下拉选择后的 Enter 意外替换正文。手机工具栏可换行，标签不拆字。

## 数据与安全
- 富文本仍存 Tiptap JSON marks，不将正文转成不受控 HTML。编译器输出安全的行内 font-family/font-size/color。
- 字体拒绝 CSS 声明注入；字号验证范围 8–96px，工具栏提供常用档位。
- 加粗默认跟随主题色，但显式文字颜色优先，编辑和导出一致。
- 原样 HTML 使用浏览器编辑事务保留原生撤销/重做；选区必须属于当前编辑器，内容变化后旧选区不再应用。
- 跨表格单元格格式化拒绝执行并提示，不破坏表格结构；同一单元格文字可调整。
- 修改字体/字号不改 SVG 及 foreignObject 的字体。原生 B/I/U/颜色操作涉及 SVG 时拒绝。
- 保留现有 HTML 净化、保存和导出流程；不修改图片及相邻未选中文字。

## 回归与证据
- 单测：textTypography.test.ts、selectedTextStyle.test.ts、selectedTextStyleSvg.test.ts。
- 浏览器/API：tests/e2e/text-typography.spec.ts（8 项），覆盖字体字号、光标输入、混合格式、颜色叠加、撤销重做、保存/刷新/编译导出、390px 手机键盘、HTML 跨段及表格边界/过期选区。
- 截图：visual-evidence/text-typography/rich-desktop.png、phone.png。
- Chromium 实测；Firefox/Safari 尚未验收。HTML 依赖 execCommand，浏览器不支持时显示失败，不伪报成功。
- 封面标题、图库说明、时间轴等字符串字段仍保留纯文本编辑，未做字段富文本迁移。不可宣称所有模块的任意文字均支持逐字格式。
- 全仓覆盖率由统一质量门禁统计，本功能局部测试不代表全仓达到 90%。
