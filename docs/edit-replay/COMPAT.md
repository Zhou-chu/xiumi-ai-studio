# 编辑回放的导出兼容性

回放可在编辑器内播放、拖动进度条、保存和重开。按用途区分以下产物：

- **本地 HTML（保留回放）**：可在桌面浏览器打开，保留 SVG 文字与动画；
  含回放的文章仅内嵌本机已索引 PNG/JPEG，不请求外部图源；若素材缺失、版本
  不符或超限，将停止下载。生成文件保留该图片与动画，断网仍可打开。
  普通、不含回放的文章里原有外链不保证离线显示。
- **秀米离线导入文件**：当前导出支持不含回放图片的 SVG 文字和动画。
  上游 `550c0ef` 也明确拒绝回放 SVG 内部的本机图片走离线替换路线：
  秀米不接受内嵌图片，SVG 内部的图片也无法像普通模块那样替换。
- **先处理图片再下载秀米导入包**：上游实现可在明确同意后，将图床返回的地址
  写入 SVG，按写入后的实际长度重新分包。当前 fork 含回放的文章仍不在界面开放
  此操作。独立的自动化验收使用注入的内存映射，验证固定文稿预检、仅允许图片
  映射、重编译后分别检查 SVG href / HTML src / CSS URL，并在最终下载前按
  实际份数再次确认。素材带版本时会将原版本传给上传适配器，不替换为最新版本。
  现有接口逐张校验与上传，未提供整批只读预检，因此本候选不接通实际上传。
  取消最终下载不代表已经处理的图片被撤回。验收没有访问
  真实微信或秀米，也不代表已验证导入或已经具备发布条件。

含回放的文章仍不开放公众号富文本复制、推送草稿箱或实网发布。普通、不含回放
的文章维持既有导出流程。秀米导入、公众号保存及各端预览中的动画、字体、图片、
交互和体积仍需分别实测，不以本地生成产物替代。

### 批量素材校验（暂未接通界面）

内部导出适配器只接受本机素材库索引的 PNG/JPEG：先一次性预备全部素材和尺寸，
核对文稿中明确指定的 SHA-256，并把最终可上传字节冻结在内存里。图片缺失、内容
或尺寸不符、重复链接、或超限时，不会开始上传。当前边界为 32 个不同变体、每份
输入 8 MiB、合计输入 24 MiB、单张输出 1 MB、合计输出 12 MB；大图不会静默
降质或转码成另一种格式。素材原图不覆盖，校验不写素材库或云端。

首次外部调用前，界面会显示实际待传图片数并要求明确同意。
开始传输后，任何响应不完整或地址无效都会停止剩余上传和下载。错误应告知已确认
上传数及最后一项状态可能未知，不能假定撤回成功，也不能自动重试。全部上传成功
后，仍需用有效地址重新编译、检查残余本机链接，再按实际分包数量确认下载。
独立测试使用真实本机合成素材与注入的假图床，不包含实际网络传输、登录或发布。

桌面桥接候选尚未挂载到默认服务。它只接受固定 IPv4 回环监听端口的同源浏览器
请求；本地预备返回待传数量和一次性令牌，令牌只能连同原会话的 HttpOnly Cookie
使用，最长两分钟。点取消会销毁未上传的计划；过期也会自动释放。只有确认提交
同一计划后才调用上传适配器。确认已发出后，关闭窗口或取消下载不撤回图片。

现有导出窗口只有在调用方显式注入上传适配器、且窗口由同源回环桌面打开时才显示
入口。默认 Web、桌面发布路径、已有公众号复制和草稿流程不变。窗口打开时只检查
能力；点击「上传图片到微信并下载」后才生成本地计划。未确认或关闭预备中的窗口
时，不发上传请求。确认下载使用重编译后的实际分包数，不复用预计值；确认上传后
若断线，不会声称图片被撤回。接通真实传输前，还需为实际适配器设置独立请求时限。
浏览器测试拦截专用路由，仅使用合成素材及模拟图床，不得持真实凭证访问外部站点。

构建产物另有本机传输验证：运行 `pnpm build` 后执行
`node --import tsx --test tests/fixtures/hosted-replay-built.test.ts`。
测试启动正常的构建版应用，但显式注入不联网的假图床，解码 multipart 并核对媒体
类型、尺寸和字节摘要。验证预备后替换或删除原图也只会送出已核对的裁剪版本；同一路径
重新预备新版本则送出新字节。适配器不重新读文件、不转码、不使用原有上传缓存，
且每项请求最多等待十秒、不重试。超时不能证明对端未收到。此验证不接通真实微信。
