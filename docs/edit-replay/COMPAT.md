# 编辑回放的导出兼容性

含回放模块的文章可在编辑器中播放和拖动进度条，也可从「导出与发布」选择「本地 HTML（保留回放）」。下载文件保留由编辑器生成的 SVG 文字与动画；可在桌面浏览器中打开。普通文章内已有的外链素材不保证离线显示。

以下功能暂不支持含回放的文章，即使已配置公众号接口：

- 复制富文本到公众号后台、上传图片到微信图床及向公众号草稿箱推送。
- 生成秀米导入包，包括手动替换图片和微信图床两种方式。

旧分支的探针结果不等同于当前整篇文章的发布验证：秀米导入、公众号保存和各端预览仍须独立确认动画、字体、图片、交互和文件体积的表现。现有保护不因这些探针而放开。普通、不含回放的文章仍走既有导出流程。

本地自动化用纯文本示例覆盖预览、保存/重开、本地 HTML 下载与平台操作保持禁用，不访问真实公众号或秀米。
