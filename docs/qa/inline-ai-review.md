# 文中 AI 审阅验收（2026-11-13）

## 用户可见变化
- 右侧长修改列表已移除，保留生成建议与回到文中审阅入口。
- 修改位置旁的编号打开小气泡；显示前后文本、理由、接受/拒绝和上一条/下一条。多槽位修改可从对应位置打开，但接受操作仍为整项原子更新。
- 手机自动切到画布，菜单、气泡支持 Escape 和焦点返回。文稿的白底、字体和导出内容不受浮层污染。
- 重复点击不会重复插入；手工编辑、删除、重排或撤销后不会用过期建议覆盖原文。批量处理和建议预览共用安全规则。

- lint、TypeScript、457 项单测通过；生产构建通过（保留现有 chunk 大于 500 kB 警告）。
- 5176 独立生产构建经真实 Chromium 在桌面/手机验证 marker、气泡、接受/拒绝和模拟保存，接受前文稿 DOM 不变，无越界；全 API 合成拦截，无真实数据写入或付费模型调用。另一次只读启动检查文章画布可见且无 pageerror。未替换原 5174。

## 边界与缺口
- AI 响应使用明确标记的合成 provider；未做本轮真实模型生成质量验证。
- 最多展开一个气泡，长内容气泡可滚动，可能遮挡邻近正文；正文和当前目标可继续定位/滚动。
- 已标记过期的项不能单条拒绝，可结束本轮审阅；未把过期误记为用户拒绝。
- 真实手机硬件、Safari/Firefox 和屏幕阅读器人工验收未完成。
- 没有创建新的整合 PR，也没有替换生产部署。
