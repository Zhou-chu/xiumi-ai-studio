# 旧编辑器分支的整合范围（草稿）

这次整合保留旧分支提交历史；不把旧测试或旧发布程序批量重新启用。以下说明区分当前实现、用新方法替代的旧实现，以及仍未兼容的行为。

- **由当前实现接手**：编辑器窄屏键盘焦点、模型列表无障碍/触控与长名称、文本框子模块、滚动时的图片级拖放与回放预览、选区变化时丢弃过期 AI 结果、混合字号/字体显示、导入颜色对比与选择切换后停止图片收集。保留当前回归与机器可读结果。历史测试使用的特定截图、旧 API/选择器和专用诊断命令不自动进入现行套件。
- **本次移植**：剪贴板带明确正文标记的阅读页现在只取正文及标题，并修正该外壳的负横向边距；保持普通富文本/公众号取文规则、Markdown 列表和既有清洗策略。没有引入基于全页权重的宽泛自动识别。
- **发布工具替代**：保留现行架构和 Sonar 门禁、两个 Node 版本、Node 24 单来源构建预览及真实 Windows EXE 验证。旧 launcher、Windows 单独打包工具和调试脚本不进入运行入口；它们的原始文件仍可在旧提交中查阅。
- **未兼容**：旧的全分类在线备份、应用内恢复、系统数据/日志目录操作及保存后退出未恢复。现行便携包按自身数据路径运行，支持指定本地数据目录、项目与素材 ZIP，以及离线恢复旧版兼容的项目和已索引素材；不自动迁移或覆盖原目录。也没有恢复旧的跨片段 SVG 依存关系、字体光栅回放、秀米/微信回放发布、旧界面色板、可放宽的 AI 选区策略或失焦自动请求。具体边界见便携包说明和[回放兼容性](../edit-replay/COMPAT.md)。
- **待验收**：这是 fork 的对照整合说明，不代表上游同步、发布成功或完整行为等价。落到主分支后需在实际提交复核 CI、Sonar 和便携包用户流程，再进行任何分支清理。
