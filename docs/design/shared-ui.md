# 共同 UI 设计规范：黑白研究与创作工作台

版本：2026-11-13 · Notebook / Xiumi 共用核心。本文是当前规范，不是营销页模板。产品根 DESIGN.md 记录产品流程与例外，不得悄悄改写共同核心。用户最新反馈优先，变更需同步两仓并记录版本及校验值。

## 1. 设计来源与取舍

- WIRED：出版物标题、开放条目、细线与精确对齐。
- Oura：暖纸白、Serif/Sans 分工、长期阅读节奏。
- Oracle：背景、面板、悬停、装饰线、必要控件边界分别定义。
- xAI：近黑外壳，克制的等宽编号与技术元信息。
- Runway：轻容器、内容优先、不过度卡片化。
- 用户参考图提供中文出版物气质；最新反馈允许黑灰扩散渐变和柔和 Liquid Glass 浮层。

不搬运营销大标题、夸张留白、摄影头图、彩卡、蓝紫渐变、装饰AI图标或胶囊堆叠。五组外部深色预览曾无法访问，不能声称逐张看过。

来源索引：https://github.com/VoltAgent/awesome-design-md 。参考只提供方向，真实流程和下述规则才是实现依据。

## 2. 先设计任务，再设计形状

每页只说明一个主要任务，主操作始终可发现。主操作、当前范围/对象、运行状态、失败及未保存状态不可为好看而隐藏。低频配置、诊断、历史版本、批量维护可移独立页/浮层或默认折叠；收起不取消已提交任务、不重放请求。任何入口搬迁须检查返回路径、键盘焦点与草稿保留。

列表优先开放条目与分隔线。只有确需独立选择、预览或操作时使用卡片。列表页舒展，阅读/编辑/问答工作台紧凑但不挤成细竖条。

## 3. 字体角色与唯一字阶

| 角色 | 字体 | 字号 / 行高 |
| --- | --- | --- |
| 页面主标题 | 本地 Noto Serif SC 或已验证中文宋体 | 32 / 42px |
| 分区标题 | 同一标题字体 | 20 / 28px |
| 条目标题 | Noto Sans SC，必要时标题宋体 | 16–18 / 26–30px |
| 正文、问答、表单输入 | 本地 Noto Sans SC 或已验证同类 | 16 / 28px |
| 导航、按钮、表单标签 | 同一无衬线字体 | 14 / 22px |
| 真正次级元信息 | 同一无衬线字体 | 12 / 18px |
| 页码、短编号、快捷键、代码 | 一套等宽字体 | 按角色；代码独立行高 |

- 12px只用于时间、计数、短编号、非必要说明。不能用在主要导航、按钮、表单标签、错误、警告、必要说明或正文。禁止10/11px微字和以缩字塞布局。
- 不允许组件自创字号、字重或行高。新增例外必须注明内容角色与真实截图理由；长文Markdown使用统一标题映射，不让每条回答自行决定。
- 中文自然字距；不把英文眉题的宽字距套给中文。标题不靠无意义英文小标签装饰。
- 本地托管字体、保留授权、按需加载与可靠回退；检查中文和标点实际加载。CSS声明本身不是字形命中证明。

## 4. 色彩、层级与对比

| token | 浅色 | 深色 |
| --- | --- | --- |
| 背景 | #F2F1ED | #141414 |
| 面板 | #FAF9F6 | #1B1B1A |
| 悬停/选择 | #E8E7E1 | #252524 |
| 主要文字 | #20201E | #ECECE6 |
| 次要文字 | #595952 | #B6B6AE |
| 辅助文字 | #66665F | #96968F |
| 装饰线 | #D5D4CE | #393937 |

控件边界、键盘焦点、错误、成功、警告各用独立token。普通文字及必要操作至少4.5:1；必要边界/焦点至少3:1。不能拿装饰线作输入框唯一边界。语义色与文字同时存在；Xiumi红绿审阅属于语义表达，不是装饰色。

## 5. 黑灰扩散与 Liquid Glass 边界

- 大面积深色外壳允许静态、低对比、黑灰径向扩散，不允许彩色光斑。最亮处必须纳入对比测试。
- 阅读、问答、笔记、编辑器使用稳定不透明底色；不能让文字下有明暗漂移。
- 玻璃仅用于悬浮弹窗、菜单、小型工具层。柔和外轮廓可18px，内控件6px；普通工作台控件仍0–4px。不是整页大圆角卡片。
- 克制透明底、静态背景模糊、细边缘高光；按实际底图最差黑/白合成验4.5:1。不依赖玻璃辨识边界。
- 无backdrop-filter回退实色；prefers-reduced-transparency及forced-colors禁透明/模糊/渐变；prefers-reduced-motion禁动画与过渡，不必删除静态玻璃。
- 不做指针跟随光、动态噪声、连续滤镜动画、多重全屏模糊。不得宣称性能改善而无测量。

## 6. 布局、间距和响应式

使用4/8/12/16/24/32/48px有限间距，1px边线。容器正常居中；禁止凭参考图照抄横向偏移。宽屏列表可双列，窄屏单列；工作台通过折叠/聚焦模式释放阅读或编辑空间。

每个页面须在1440×900、1024×768、390×844检验。长标题、长文件名、错误文案、中文换行、空数据与多条内容不能溢出。控件触达高度通常44px，焦点不得被裁切。文字放大不能靠固定高度剪掉内容。

## 7. 状态与无障碍

按钮、输入、菜单与浮层覆盖默认/hover/focus/disabled/loading/error。关闭/Escape恢复合理焦点；模态时背景不可操作。不要在已有手机模态内随意Portal到body造成焦点冲突。表单有真实label，图标按钮有名称；装饰与功能严格区分。异步结果未知与失败不同，禁止自动重放已可能提交的动作。

## 8. 防止 AI 任意排版的实施约束

1. 修改前列明页面任务、主要对象、主操作、低频项；不能仅凭“更高级”加卡片或改布局。
2. 先复用token及已有组件；不得在局部inline style硬编码新字号/色值/圆角。
3. 新小字须说明信息是否可省略。若执行任务离不开它，至少14px。
4. 不为视觉整洁隐藏错误、当前范围、未保存提示、关闭/返回或真实处理状态。
5. 不凭空增加统计、徽章、AI图标、励志文案、英文章节标签或无业务意义空白。
6. 不用一串全局!important覆盖掩盖层级冲突；指出样式拥有者并测试cascade。
7. 先运行相关测试，再用真实页面/真实数据流程验收；mockup不是上线证明。
8. 截图记录版本、视口、主题、场景；必须读图而非只保存文件。未测项目明确列出。

## 9. 产品差异及质量门禁

Notebook：资料选择与打开阅读独立，问答范围可见；资料/阅读/问答可聚焦，引用定位原文，成果可再次找到。
Xiumi：资源—画布—属性三栏服务导入、编辑、排版、保存、导出。中央准确呈现白底公众号文章，不为深色应用强行变黑。用户作品、模板、正文格式与导出HTML独立于UI；禁止全局反色/灰度滤镜或字体继承污染内容。

Xiumi AI审阅直接显示完整红色原模块和其下绿色建议模块；右上气泡明确绿色接受/红色拒绝。颜色属于审阅语义，不进入文稿或导出。过期/重复保护、撤销、Ctrl/Cmd多选及右侧范围同步不能为视觉重构牺牲。复杂模型配置按任务分组而非挤成窄长表单。

质量报告必须分开：测试通过率、代码覆盖率、静态检查、code smell/维护性评分、视觉与无障碍验收。全项目覆盖目标>90%须对完整一方生产源码计入未导入文件，并说明各语言/子项目分母、排除规则与语句/分支/函数/行四指标，目标每项均大于90%；工具未提供的指标必须标明未测，不可虚构。不能缩小include、排除难测业务、删除断言凑分。

code smell>90只接受明确工具、版本、规则集、原生评分定义及完整报告；若工具只给问题数量或A–E评级，原样报告，不能把lint全绿转换成100分。未建立可复现指标前标记未测。
